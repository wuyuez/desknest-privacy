DeskNest

Help & Support

A little company for your desk. Use an iPhone on its own or connect a compatible DeskNest screen.

Updated November 13, 2026 · DeskNest 1.1.0

Start with one iPhone

On Home, tap Add Device and choose to use this iPhone as a display. In Desktop Settings, choose a layout, select a region and pick a clock, photos, focus timer or day counter. Save and tap Start Display. The bottom Home shortcut opens the saved display directly. No accessory is required.

Set up another iPhone

Install the same DeskNest version on both phones. Allow Local Network access and use the same local network with device-to-device communication. Put one phone in display mode; on the other, add an old iPhone, select it and approve the first connection on the display phone. Keep both apps in the foreground. Reconnect by selecting the device again. Update both phones together because pairing protocols can differ between versions.

Connect a DeskNest screen

The screen is separate physical hardware. A compatible model and firmware and continuous power are required. The app helps with Wi-Fi setup, interfaces, content, brightness and alert volume. Wi-Fi switching and firmware updates appear only when supported. Follow the in-app instructions and use trusted firmware for the exact model. Cloud remote control is not provided.

Photos and backgrounds

Select photos using the system photo picker, confirm each crop and save. DeskNest receives only selected images, does not request full photo-library access and does not change originals. Each iPhone photo component holds up to six photos; the screen album holds up to two. iPhone backgrounds support cropping, blur and fade. Screen styles and background options depend on firmware.

Weather coverage

Weather currently supports cities in China only and needs internet access. Choose a city manually; no system location permission is requested. Data comes directly from weather.com.cn. Follow the app's update and stale-data notices. Clocks, photos, focus and day counters do not require weather. Availability in your App Store does not imply local weather coverage.

System, language and focus

DeskNest supports iPhone with iOS 16 or later. Keep the app in the foreground for display and iPhone focus-completion alerts. Alerts follow your silent mode and volume. The Home gear menu lets each phone choose English, Simplified Chinese or Traditional Chinese. A screen's own language depends on firmware.

Cannot find a device?

Check matching app versions, Local Network permission and a local network that allows devices to communicate. Guest networks or router client isolation may block discovery. Keep the display iPhone in the foreground and the screen powered, then search again. Do not share device addresses, Wi-Fi passwords or pairing tokens publicly.
